# Настольная хоррор-игра «НЕЧТО» (Stay Away!) для Discord

Полная онлайн-адаптация психологической дедуктивной настольной игры **«НЕЧТО» (Stay Away!)** для игры с друзьями через голосовой чат Discord.
Атмосфера полярной станции «Аванпост 31» из легендарного фильма Джона Карпентера «Нечто» (1982).

---

## ❄️ Особенности игры

- **Атмосферный дизайн полярного бункера**: глубокая арктическая ночь, неоновая ледяная подсветка, тревожные аварийные маяки, процедурный звук на Web Audio API (сирены, огнемёт, стук дверей, пульс).
- **Овальный стол на 4–12 полярников**: динамическое размещение игроков, индикаторы направления хода, заколоченные двери на стыках мест, ледяной купол карантина.
- **Полная колода «НЕЧТО» на русском языке**:
  - **НЕЧТО**: секретный монстр, цель которого заразить или уничтожить станцию.
  - **Заражение**: тайная передача вируса при обмене картами.
  - **Огнемёт**: сжигает соседа дотла (если это Нечто — победа Людей!).
  - **Топор**: крушит заколоченные двери или освобождает из карантина.
  - **Анализ крови и Подозрение**: проверка чистоты соседа.
  - **Виски**: раскрывает карты всем полярникам за столом.
  - **Заколоченная дверь**: блокирует атаки и обмен картами с соседом.
  - **Карантин**: изолирует опасного исследователя на 2 раунда.
  - **Защита («Нет, спасибо!», «Мимо!», «Страх»)**: 15-секундное тревожное окно реакции при нападении!
  - **Паника («Смена направления», «Слепое доверие»)**: мгновенный розыгрыш при доборе.
- **Безопасность скрытой информации (Zero-Leak)**: карты в руке и тайная роль (Нечто / Зараженный / Человек) строго изолированы. Никто не может подсмотреть чужие роли через DevTools.
- **Интеграция с Discord**: генерация 6-значных кодов комнат и 1-клик копирование ссылки для друзей.
- **Встроенные ИИ-боты**: возможность в один клик протестировать игру соло или добавить недостающих полярников в лобби.

## 🚀 Быстрый запуск локально

1. Убедитесь, что установлен **Node.js 18+**:
   ```bash
   node -v
   ```

2. Установите зависимости (если еще не установлены):
   ```bash
   npm install
   ```

3. Запустите сервер для разработки:
   ```bash
   npm run dev
   ```

4. Откройте в браузере:
   [http://localhost:3000](http://localhost:3000)

> 💡 **Совет для быстрого теста:** На главной странице нажмите **«Быстрый соло-тест: начать сразу с 3 ботами»**, чтобы мгновенно начать игру с 3 ИИ-исследователями без ожидания друзей!

## 🌐 Сетевая игра через интернет (Firebase)

Игра поддерживает работу как в локальном мульти-вкладочном режиме (через `BroadcastChannel` и `LocalStorage`), так и через бесплатный **Firebase Firestore** для полноценной игры с друзьями через интернет.

### Инструкция по настройке Firebase (занимает 3 минуты):
1. Перейдите в [Firebase Console](https://console.firebase.google.com/) и создайте бесплатный проект.
2. В разделе **Build -> Firestore Database** нажмите **Create Database** (выберите тестовый режим).
3. В разделе **Project Settings -> General** нажмите **Add app -> Web (</>)** и скопируйте конфигурацию.
4. Создайте в корне проекта файл `.env.local` и вставьте ваши ключи:
   ```env
   NEXT_PUBLIC_FIREBASE_API_KEY=AIzaSy...
   NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your-project.firebaseapp.com
   NEXT_PUBLIC_FIREBASE_PROJECT_ID=your-project
   NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your-project.appspot.com
   NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=123456789
   NEXT_PUBLIC_FIREBASE_APP_ID=1:123456789:web:abcdef
   ```
5. Разверните правила безопасности из файла `firestore.rules`.

## ☁️ Деплой на Vercel (Бесплатный хостинг)

1. Загрузите код в GitHub-репозиторий.
2. Перейдите на [Vercel](https://vercel.com/) и импортируйте репозиторий.
3. В настройках проекта (**Environment Variables**) добавьте переменные из `.env.local`.
4. Нажмите **Deploy**. Готово! Делитесь ссылкой с друзьями в Discord.

## 📖 Краткие правила игры

- **Цель Людей**: найти Нечто и сжечь его огнемётом.
- **Цель Нечто**: заразить всех полярников за столом или уничтожить здоровых людей.
- **Ход полярника**:
  1. **Добор**: берет 1 карту из колоды (рука становится 5 карт).
  2. **Действие**: разыгрывает 1 карту (действие/препятствие) или сбрасывает 1 карту в закрытую (в руке 4 карты).
  3. **Обмен**: предлагает 1 карту соседу по направлению хода. Сосед может защититься или отдать карту в ответ.
  4. Если Нечто передает карту «Заражение» — получатель тайно становится Зараженным и переходит в команду монстра!
